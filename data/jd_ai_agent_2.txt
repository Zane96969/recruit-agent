职位名称：AI Agent 开发工程师（中级）
工作地点：深圳
薪资范围：15K-25K · 14薪

【岗位职责】
1. 负责基于大语言模型（LLM）的智能体（Agent）应用开发，重点实现工具调用（Function Calling）与检索增强（RAG）。

3. 对接业务系统 API，封装成 Agent 可调用的工具链。
4. 跟踪大模型前沿技术，持续优化 Agent 的稳定性与回答质量。

【任职要求】
1. 本科及以上学历，计算机相关专业，2 年以上开发经验。
2. 熟练掌握 Python，熟悉 OpenAI 兼容接口的调用。
3. 有 RAG、Function Calling 实战经验，熟悉 LangChain 框架。
4. 了解 LangGraph 或 Milvus 向量数据库者优先。
5. 具备良好的问题排查能力与团队协作意识。
