职位名称：AI Agent 开发工程师（校招 / 实习可转正）
工作地点：北京 / 远程
薪资范围：12K-20K · 14薪

【岗位职责】
1. 负责基于大语言模型（LLM）的智能体（Agent）应用设计与开发，覆盖需求拆解、工具调用、检索增强（RAG）等核心环节。
2. 搭建并优化 RAG 流水线，包括文档切块、向量检索、混合检索（BM25 + 向量）、重排（Rerank）与防幻觉控制。
3. 对接各类内部系统与第三方 API，将其封装为 Agent 可调用的工具（Function Calling）。
4. 建立 Agent 效果评估体系，通过测试集持续跟踪命中率、忠实度等指标并迭代优化。
5. 与产品、业务团队协作，将 Agent 能力落地到真实业务场景。

【任职要求】
1. 本科及以上学历，计算机、软件工程等相关专业，2027 届应届生优先。
2. 熟练掌握 Python，了解 HTTP、JSON、RESTful API 等基础概念。
3. 理解大模型基本原理，熟悉 OpenAI 兼容接口，有 Prompt 工程、Function Calling、RAG 实战经验者优先。
4. 熟悉 LangChain、LangGraph 等框架，或使用过 Chroma、Milvus 等向量数据库者优先。
5. 学习能力强，对 AI 应用有热情，具备良好的问题拆解与沟通能力。

【福利待遇】
弹性工作、五险一金、年度体检、免费三餐、GPU 算力支持、扁平技术氛围。
