职位名称：Java 后端开发工程师
工作地点：上海
薪资范围：10K-18K · 13薪

【岗位职责】
1. 负责公司后端服务的设计、开发与维护，保障系统的稳定性与性能。
2. 参与系统架构设计，编写高质量、可维护的 Java 代码及单元测试。
3. 设计并维护 RESTful API，与前端团队协作完成接口对接。
4. 负责数据库表结构设计与 SQL 优化，处理线上问题与性能瓶颈。
5. 参与代码评审、技术分享，推动团队工程规范落地。

【任职要求】
1. 本科及以上学历，计算机相关专业，1-3 年经验或优秀应届生。
2. Java 基础扎实，熟悉集合、多线程、JVM 及常用设计模式。
3. 熟练使用 Spring Boot、MyBatis 等主流框架，了解微服务架构。
4. 熟悉 MySQL、Redis，掌握基本的数据库优化与缓存使用。
5. 具备良好的编码习惯、团队协作能力与责任心。

【福利待遇】
五险一金、年终奖、带薪年假、定期团建、技术培训、股票期权激励。
